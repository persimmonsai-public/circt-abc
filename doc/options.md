# Option reference (generated)

GENERATED by `python3 -m circt_flow options --markdown > doc/options.md` from `scripts/circt_flow/options.py`; do not edit by hand (a test fails when it is stale).

Precedence, highest first: argument (`--set NAME=VALUE`), legacy environment variable (transition only), recipe (the flow.yaml: `options:` and its sections), tech-pack `flow:` default, built-in default. Every run writes `settings.json` (value and source of every option, the tool commit, the pass pipeline as executed).

## Deprecation

The legacy `CIRCT_FLOW_*` / `CIRCT_VT_*` variables are accepted, with one warning each naming the replacing attribute, in release 11 (the release that ships this registry) and release 12; from release 13 on they are refused (`options.LEGACY_ENV_REMOVED_IN`). `--strict` refuses them now, and refuses any unknown `CIRCT_FLOW_*` / `CIRCT_VT_*` name in the environment.

Legacy values are read exactly as the old code read them: a flag is `1` or `0` (anything else is an error; earlier releases read it as off, or as on for a default-on flag); a number has no blank and no leading zero; an empty value is unset, except `CIRCT_FLOW_ADDER_ARCH=` (empty), which keeps its old meaning (set-adder-arch runs with an empty arch). A pack's `flow.env` (legacy names) is a tech-pack default: it ranks below the flow.yaml and the environment (before the registry it was copied into the process environment, above the flow.yaml's shift_select keys, and was inherited by child processes); `--strict` refuses it.

## Release procedure

Every public release bumps `CURRENT_RELEASE` in `scripts/circt_flow/options.py` (now 11) in the same commit as the release. `tests/test_options.py::test_legacy_shim_removed_by_its_release` fails while `CURRENT_RELEASE >= LEGACY_ENV_REMOVED_IN` and any option still has a legacy variable: the release that reaches it must first remove the shim (`legacy_env`, `legacy_mode`, `INTERFACE_VARS` stay).

Options marked pack-only are recorded from the tech pack's `flow:` section for the record; `--set` and `options:` refuse them.

An option value that contains commas (a list) must not travel through `sbatch --export=...` or another wrapper that passes variables as a comma-separated list: the value is cut at its first comma (the run silently gets only part of the list). Pass them with `--set` or in the settings file; the flow's own submit and container paths (closure ladder, ORFS P&R, OpenSTA) carry no option that way.

## Environment variables that are not options

Exported by the flow to a pack's P&R command or a ladder rung (allowed under `--strict`):

* `CIRCT_FLOW_LADDER_PARAM`: closure ladder: the parameter, exported
* `CIRCT_FLOW_LADDER_RUNG`: closure ladder: the rung's index (pack command), exported
* `CIRCT_FLOW_LADDER_VALUE`: closure ladder: the rung's value (JSON), exported
* `CIRCT_FLOW_OUT`: closure ladder: the flow's output directory, exported
* `CIRCT_FLOW_PACK_SETTINGS`: closure ladder: the rung's pack_settings.json (when pack options are handed over), exported to accept.command
* `CIRCT_FLOW_PNR_METRICS`: closure ladder: the rung's pnr_metrics.json, exported
* `CIRCT_FLOW_RUNG_DIR`: closure ladder: the rung's directory, exported to the rung's command
* `CIRCT_FLOW_RUNG_INDEX`: closure ladder: the rung's index, exported
* `CIRCT_FLOW_START_AT`: closure ladder: stage a rung starts at (pack command), exported
* `CIRCT_FLOW_START_FROM`: closure ladder: placement directory a rung restarts from, exported
* `CIRCT_FLOW_STOP_AFTER`: closure ladder: stage the shared placement stops after, exported
* `CIRCT_FLOW_WIRE_RC`: setup corner's wire RC Tcl, exported to a pack's P&R command (wire_rc.pnr_env)
* `CIRCT_FLOW_WIRE_RC_<...>`: per-corner wire RC Tcl (CIRCT_FLOW_WIRE_RC_<CORNER>), exported

Tool, build and location variables (not options; unchanged):

* `ABC_BIN`: ABC binary
* `ABC_PARTITIONS`: --partitions default (config.py; has a CLI flag and a pack default)
* `ABC_POOL_SIZE`: --abc-pool-size default (config.py)
* `CIRCT_ABC_ALLOW_REPO_OUT`: allow a private pack's run inside the repo
* `CIRCT_ABC_CACHE`: cache directory
* `CIRCT_ABC_OPT`: circt-abc-opt binary
* `CIRCT_ABC_PROVENANCE`: liberty provenance check mode
* `CIRCT_ABC_TECH_PATH`: tech pack search path
* `CIRCT_OPT`: circt-opt binary
* `CIRCT_VERILOG`: circt-verilog binary
* `ENABLE_CLASSICAL_RESUB`: abc-bridge resub (config.py; has a CLI flag and a pack default)
* `HOME`
* `LIBPINS_LIBS`: design/libpins.py instrument
* `OPENSTA`: local OpenSTA binary
* `ORFS_HOME`: local ORFS checkout
* `ORFS_IMAGE`: ORFS image
* `PYTHONPATH`
* `SV2V`: sv2v binary
* `SV2V_DOCKER_IMAGE`: sv2v image
* `XDG_CACHE_HOME`: cache base
* `YOSYS`: yosys (tests)
